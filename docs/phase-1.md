# Phase 1 Definition of Done

1. Docker starts PostgreSQL and Redis.
2. `pnpm install` succeeds.
3. Prisma Client generates.
4. Database schema can be pushed.
5. Seed creates demo organization, branches, admin, products and sales.
6. NestJS health endpoint responds.
7. Login returns JWT.
8. Dashboard displays database-backed KPIs and charts.
9. TypeScript build succeeds.
10. Basic API test passes.

Later phases add full RBAC, inventory, purchasing, sales, finance, Excel/Graph, AI and Azure production deployment.
